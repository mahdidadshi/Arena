# میز کار ایجنت اسمارت مانی (SMC)

اپلیکیشن کاربردی تحلیل معاملات با روش اسمارت مانی (SMC/ICT): تشخیص نقدینگی، ساختار بازار، تله‌های روانی، سشن‌ها، پروفایل والیوم، اردربلاک و FVG — به‌همراه **پلن معاملاتی کامل (ورود/حد ضرر/اهداف)**، **چک‌لیست تأییدیه‌ها**، **ماشین‌حساب حجم پوزیشن و ریسک** و **ژورنال معاملات با آمار عملکرد** روی چارت کریپتو، سهام آمریکا و فارکس/کالا.

---

## سه راه استفاده از برنامه

| روش | مناسب برای | سختی |
|---|---|---|
| ۱. نصب مستقیم به‌صورت اپ (PWA) | استفاده سریع روی گوشی/کامپیوتر از همان لینک فعلی | خیلی آسان — ۳۰ ثانیه |
| ۲. اجرای کامل روی کامپیوتر شخصی | مالکیت صددرصدی برنامه و دیتابیس ژورنال | آسان — ۵ دقیقه |
| ۳. انتشار آنلاین روی هاست | دسترسی از هر جا با یک لینک دائمی | متوسط |

---

## روش ۱: نصب به‌عنوان اپ (PWA) — پیشنهادی

برنامه به‌صورت PWA ساخته شده؛ یعنی بدون نصب هیچ چیز، همان لحظه مثل یک اپ واقعی روی دستگاه شما «نصب» می‌شود: آیکون مستقل، اجرای تمام‌صفحه بدون نوار آدرس، باز شدن سریع و کار آفلاین روی رابط کاربری.

- **اندروید (کروم):** دکمه «نصب برنامه» داخل هدر برنامه را بزنید، یا منوی سه‌نقطه ← **Add to Home screen / Install app**
- **iOS (سافاری):** دکمه اشتراک‌گذاری ← **Add to Home Screen**
- **ویندوز / مک (کروم، ادج):** دکمه «نصب برنامه» داخل هدر، یا آیکون نصب در نوار آدرس ← **Install**

> نکته: دیتابیس ژورنال در روش PWA روی همان سروری است که برنامه از آن اجرا می‌شود. اگر می‌خواهید ژورنال کاملاً روی سیستم خودتان باشد، از روش ۲ استفاده کنید.

## روش ۲: اجرای کامل روی کامپیوتر شخصی (نسخه مستقل)

### پیش‌نیاز
- **Node.js نسخه ۲۰ یا بالاتر** — از [nodejs.org](https://nodejs.org) نسخه LTS را نصب کنید (در زمان نصب، گزینه‌های پیش‌فرض کافی است).

### مراحل اجرا
1. فایل `smc-trading-desk.zip` را در یک پوشه باز (Extract) کنید.
2. داخل همان پوشه یک پنجره ترمینال باز کنید:
   - ویندوز: در نوار آدرس پوشه تایپ کنید `cmd` و اینتر بزنید
   - مک/لینوکس: راست‌کلیک در پوشه ← Open Terminal
3. دستورهای زیر را به‌ترتیب اجرا کنید:

```bash
npm install          # نصب وابستگی‌ها (فقط بار اول، چند دقیقه طول می‌کشد)
npx prisma db push   # ساخت دیتابیس ژورنال (فقط بار اول)
npm run dev          # اجرای برنامه
```

4. مرورگر را باز کنید: **http://localhost:3000**

### اجرای دائمی (حالت پروداکشن)
یک بار بیلد بگیرید، بعد از آن هر بار فقط `npm start`:

```bash
npm run build    # فقط بار اول و بعد از هر به‌روزرسانی
npm start        # اجرای سرور سبک و سریع پروداکشن
```

سرور روی همه اتصالات شبکه بالا می‌آید. برای توقف، Ctrl+C بزنید یا پنجره را ببندید.

### شروع خودکار با روشن شدن ویندوز (اختیاری)
1. در پوشه برنامه فایلی به نام `start-smc.bat` بسازید با این دو خط:
```bat
cd /d %~dp0
npm start
```
2. کلیدهای Win+R را بزنید، تایپ کنید `shell:startup` و Enter بزنید
3. یک میان‌بُر از `start-smc.bat` داخل آن پوشه بگذارید — از این به بعد با روشن شدن کامپیوتر، برنامه خودکار بالا می‌آید.

### استفاده از گوشی روی همان وای‌فای خانه
وقتی برنامه روی کامپیوتر اجراست، گوشیِ متصل به همان مودم هم می‌تواند بازش کند:
1. روی کامپیوتر در cmd دستور `ipconfig` را بزنید و عدد IPv4 را پیدا کنید (مثل `192.168.1.5`)
2. روی گوشی آدرس `http://192.168.1.5:3000` را باز کنید

> توجه: استفاده از مرورگر گوشی کامل کار می‌کند، ولی دکمه «نصب برنامه» (نصب واقعی PWA) فقط روی HTTPS یا localhost ظاهر می‌شود. برای تجربه اپ‌مانند روی موبایل، از روش ۱ (لینک فعلی) یا روش ۳ با SSL استفاده کنید.

### نکته‌های مهم
- **دیتابیس:** SQLite است و خودکار ساخته می‌شود (فایل `prisma/dev.db`). تمام پلن‌ها و ژورنال شما فقط روی سیستم خودتان ذخیره می‌شود — کاملاً خصوصی.
- **دیتای قیمت:** کریپتو از Binance و سهام/فارکس از Yahoo Finance خوانده می‌شود؛ اینترنت لازم است. **اگر دسترسی شما به بایننس محدود است (خطای دریافت دیتای چارت کریپتو)، VPN روشن کنید** — سهام و فارکس معمولاً بدون VPN هم کار می‌کند.
- **موتور تحلیل هوش مصنوعی:** در نسخه لوکال، استدلال متنی LLM ممکن است در دسترس نباشد؛ در این صورت برنامه به‌صورت خودکار از «موتور جایگزین قطعی» مبتنی بر قوانین SMC استفاده می‌کند و تمام بخش‌های دیگر (پلن، چک‌لیست، ماشین‌حساب، ژورنال) بدون تغییر کار می‌کنند.
- اگر **Bun** را ترجیح می‌دهید: `bun install` و `bun run dev` هم دقیقاً همین خروجی را می‌دهد.

## روش ۳: اجرای ابری ۲۴/۷ (دسترسی از هر جا + نصب واقعی PWA روی گوشی)

**گزینه الف — سرور مجازی VPS (توصیه‌شده، حدود ۴ دلار در ماه):**
1. یک VPS سبک بخرید (مثلاً اروپا با اوبونتو ۲۴)
2. Node.js 20 نصب کنید، بسته zip را آپلود و باز کنید
3. `npm install` ← `npx prisma db push` ← `npm run build`
4. `npm i -g pm2` و بعد `pm2 start scripts/start-prod.js --name smc` و `pm2 save` — برنامه ۲۴/۷ بالا می‌ماند
5. (اختیاری) با Caddy یا Nginx دامنه + SSL رایگان اضافه کنید تا روی گوشی هم دکمه «نصب برنامه» فعال شود

**گزینه ب — هاست رایگان مثل Vercel (بدون هیچ اکانت اضافه):**
کد را در GitHub بگذارید و در vercel.com ایمپورت کنید — بدون هیچ تنظیم اضافه‌ای دیپلوی می‌شود. همه امکانات (تحلیل، پلن، چک‌لیست، ماشین‌حساب ریسک) کامل کار می‌کنند؛ فقط ژورنال «موقتی» است (مراحل کامل فقط با گوشی در بخش بعدی). اگر بعداً ژورنال دائمی خواستید، پشتیبانی Turso هم داخل برنامه هست (بخش اختیاری انتهای بخش بعدی).

> برای استفاده شخصی روزمره، روش ۱ یا ۲ کافی است؛ روش ۳-الف وقتی است که بخواهید از هر جا با گوشی به برنامه و ژورنال دسترسی داشته باشید.

## فقط با گوشی: راه‌اندازی دائمی رایگان (فقط GitHub + Vercel)

بدون هیچ کامپیوتری و بدون هیچ اکانت اضافه — همه مراحل از مرورگر گوشی، حدود ۱۵ دقیقه، ۵ گام:

**۱) ساخت مخزن در GitHub:**
در `github.com` ثبت‌نام/ورود کنید ← دکمه + (بالا سمت راست) ← **New repository** ← یک اسم بنویسید (مثل `smc-desk`) ← **Create repository** (بقیه گزینه‌ها دست نخورده بمانند)

**۲) آپلود بسته:**
در همان صفحه ← **Add file** ← **Upload files** ← فایل `smc-trading-desk.zip` را از حافظه گوشی انتخاب کنید ← پایین صفحه **Commit changes**

**۳) اضافه کردن فایل خود-باز‌کن (فقط یک بار):**
دوباره **Add file** ← **Create new file** — در کادر نام فایل دقیقاً این‌طور تایپ کنید:
`.github/workflows/unpack.yml`
(با نقطه اول و اسلش‌ها — گیت‌هاب خودش پوشه‌ها را می‌سازد) — بعد محتوای زیر را کامل کپی و در کادر متن Paste کنید و **Commit changes**:

```yaml
name: unpack
on:
  push:
  workflow_dispatch:
permissions:
  contents: write
jobs:
  unpack:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Unzip package into repo root
        run: |
          if [ -f smc-trading-desk.zip ]; then
            unzip -o smc-trading-desk.zip -d temp
            cp -a temp/. .
            rm -rf temp
            mkdir -p public
            cp -f smc-trading-desk.zip public/
            git config user.name "unpack-bot"
            git config user.email "bot@users.noreply.github.com"
            git add -A
            git commit -m "unpack app source" || echo "nothing to commit"
            git push
          else
            echo "no package found — nothing to do"
          fi
```

حدود یک دقیقه بعد در تب **Actions** مخزن، تیک سبز ✓ می‌بینید و همه فایل‌های برنامه (پوشه `src`، `package.json` و...) داخل repo ظاهر می‌شوند. (این فایل داخل بسته هم هست — دفعات بعدی فقط کافی است zip جدید را آپلود کنید، خودش باز می‌شود.)

**۴) انتشار در Vercel:**
در `vercel.com` با همان اکانت GitHub وارد شوید ← **Add New…** ← **Project** ← کنار مخزن `smc-desk` دکمه **Import** ← هیچ تنظیماتی را تغییر ندهید ← **Deploy** ← حدود ۲-۳ دقیقه صبر کنید تا لینک دائمی شما آماده شود (مثل `https://smc-desk.vercel.app`)

**۵) نصب روی گوشی:**
همان لینک را در مرورگر گوشی باز کنید ← دکمه «نصب برنامه» در هدر (اندروید) یا منوی اشتراک سافاری ← **Add to Home Screen** (آیفون) 🎉

> **نکته ژورنال:** در این حالت همه امکانات کامل کار می‌کنند؛ فقط ژورنال «موقتی» است و ممکن است با راه‌اندازی مجدد سرور خالی شود. اگر خواستید دائمی شود، ۴ مرحلهٔ اختیاری زیر را انجام دهید.

### اختیاری: دائمی کردن ژورنال با Turso (رایگان، ۵ دقیقه)
۱. در `turso.tech` با اکانت GitHub وارد شوید ← **Create Database** ← آدرسی که با `libsql://` شروع می‌شود را کپی کنید
۲. از بخش توکن‌ها یک **Database Token** بسازید و کپی کنید
۳. در Vercel ← پروژه ← **Settings** ← **Environment Variables** دو متغیر بسازید:
   - `DATABASE_URL` = آدرس `libsql://...`
   - `DATABASE_AUTH_TOKEN` = توکن
۴. از تب **Deployments** آخرین دیپلوی را **Redeploy** کنید — جدول ژورنال در اولین اجرا خودکار ساخته می‌شود و دیتا دیگر پاک نمی‌شود.

## عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| خطای «پورت 3000 اشغال است» | `npm run dev -- -p 3001` و باز کردن آدرس جدید |
| خطای Prisma Client | یک‌بار `npx prisma generate` اجرا کنید |
| چارت کریپتو لود نمی‌شود | VPN (دسترسی به Binance)؛ سهام/فارکس از Yahoo جدا است |
| دکمه «نصب برنامه» دیده نمی‌شود | مرورگر باید PWA را تأیید کرده باشد؛ از منوی مرورگر ← Install app استفاده کنید (در iOS: Add to Home Screen) |
| `npm start` خطای Cannot find module داد | یک بار دیگر `npm run build` بزنید (بیلد ناقص بوده) |
| فونت فارسی بار اول درست نیست | فونت Vazirmatn از CDN می‌آید؛ با اینترنت پایدار بار اول کش می‌شود |

## ساختار پروژه

```
src/
├── app/
│   ├── page.tsx                ← صفحه اصلی (میز کار)
│   └── api/
│       ├── analyze/route.ts    ← تحلیل SMC + پلن ایجنت
│       ├── klines/route.ts     ← دیتای کندل‌ها + سطوح نقدینگی
│       └── journal/route.ts    ← ذخیره/به‌روزرسانی/حذف پلن‌ها + آمار
├── components/trading/
│   ├── PriceChart.tsx          ← چارت کندل‌استیک + سطوح نقدینگی/پلن
│   ├── AnalysisPanel.tsx       ← پلن معاملاتی + چک‌لیست تأییدیه + کارت‌های تحلیل
│   ├── RiskCalculator.tsx      ← ماشین‌حساب حجم/ریسک/اهرم
│   ├── TradeJournal.tsx        ← ژورنال معاملات با آمار
│   ├── InstallAppButton.tsx    ← دکمه نصب PWA
│   └── ...
└── lib/
    ├── smc.ts                  ← موتور اسمارت مانی (نقدینگی، ساختار، تله، سشن، والیوم، OB/FVG، چرخه)
    ├── styles.ts               ← ۷ سبک تحلیلی وزن‌دار
    ├── agent.ts                ← ایجنت LLM + موتور جایگزین قطعی
    ├── market-data.ts          ← Binance / Yahoo + کش
    └── db.ts                   ← کلاینت Prisma
prisma/schema.prisma            ← مدل TradePlan (ژورنال)
public/manifest.json , sw.js    ← فایل‌های PWA
```
